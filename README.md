A simple QA automation practice project created using **Python** and **Selenium WebDriver**.

This project focuses on automating basic web application testing scenarios such as browser navigation, element identification, login testing, searching, checkbox validation, and screenshot capturing.

---

## 🚀 What I Practiced

- 🌐 Browser automation using Selenium WebDriver
- 🔍 Locating web elements using:
  - ID
  - Name
  - CSS Selector
  - Link Text
- ⌨️ Automating typing and user inputs
- 🖱️ Automating button clicks
- 🔐 Login automation
- ✅ Positive and negative login testing
- ☑️ Checkbox validation
- 📸 Capturing screenshots
- 📄 Reading and printing page titles
